# Arcahv：毁灭中的喜悦

*Feryquitous · Arcaea*

[English](README.md) / 中文

《Arcahv》里有种很难说清的东西：毁灭与创造，希望与绝望，温柔与残酷，在这首曲子里竟然如此和谐。

开头的吟唱遥远而庄重，像一首圣歌。不知从哪一刻起，歌声里多了一丝异样的温暖。仿佛一位天使在给世界和世上的人轻唱摇篮曲，而她已开始亲手毁掉这一切。也许最让人不安的，是她当真爱着自己正在毁掉的一切。

人声采样带着末日的气息，节拍支离破碎却又严丝合缝，旋律轻得像悬在空中。这些声音交织在一起，自成一体。仿佛一切都在崩塌，每个声音却又恰好落在它该在的地方。**这场悲剧有一种近乎失控的美。借用 GPT 的说法，那是毁灭之中几乎让人承受不住的美，也是面对一切消亡时，一种奇异的喜悦。**

光望着 Arcaea 的天空一点点碎裂。

*“真愉快。”*

单听《Arcahv》，它已经是一首出色的作品。可是，经历过光与对立的故事，看过那片天空，再听它响起，又是另一回事了。故事给了音乐一层意义；音乐一响，那一幕便又回到眼前。是巧合，还是一早就安排好的？如今已很难把两者分开，仿佛它们生来就该在这里相遇。

## 同一个长音，两种低音

约 0:13，人声停在 B♭4，低音是 E♭1。撇开八度，两者相隔纯五度。约 1:23，同一个 B♭4 再次出现，低音却换成了 E2，原来的纯五度成了三全音。趁人声还停在那个音上，在两句之间来回切换，听听低音换了以后，同一个长音有了什么变化。[对照试听](https://glucksdrache.github.io/arcahv-appreciation/?lang=zh#comparisons)

## 从录音到谱例

转写从立体声录音开始。KUIELab MDX-Net 将录音分为四轨：人声、贝斯、鼓组，以及其余的器乐与音效。「合成还原」用振荡器和滤波噪声重新生成四个声部。人声音高约每 10 毫秒测一次，跟随吟唱中的滑音与颤音；器乐保留测得的音区，贝斯跟随各次谐波的强弱变化。鼓声既有敲下去那一刻明亮的起音，也有随后响起的低频共鸣。

可以从 11.65 秒附近的贝斯听起。低音从 G1 降到 E♭1，最突出的谐波也由二次变为三次：音高在变，音色也在变。先单听「贝斯」，再换到「人声与贝斯」，听同一句吟唱怎样落在两个不同的低音上。在九小节谱例里点一个音符，还可以查看它的音高、起始时间和时值。[全曲听辨](https://glucksdrache.github.io/arcahv-appreciation/?lang=zh) · [九小节配器谱](https://glucksdrache.github.io/arcahv-appreciation/arrangement.html?lang=zh)

「录音分轨」收录了 5.370–16.679 秒的片段，四个声部可自由组合。要听整曲分轨，选择本地文件模式和相应声部，再从设备中打开一条与曲首对齐、时长为 2:52.99 的音轨。[试听开头片段](https://glucksdrache.github.io/arcahv-appreciation/?source=recorded&lang=zh#listen)
